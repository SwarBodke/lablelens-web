Rules & methodology

A transparent screening baseline

The rule references are versioned separately from OCR patterns so the legal baseline can be updated without hiding changes inside extraction code.

How a finding is produced

  1. OCR reads each supplied panel independently, then merges deduplicated lines.
  2. Extractors preserve original declaration evidence and parse candidate values.
  3. Six grouped checks evaluate the evidence with package/listing context.
  4. Any definite issue produces Potential non-compliance; unresolved evidence produces Needs review.
  5. Only when every applicable grouped check passes is the result Compliant.

Important boundaries

  • Actual net contents require weighing/measurement and are not verified from a photograph.
  • Font size needs calibrated physical measurement; pixels alone are not millimetres.
  • Category-specific exemptions and later notifications must be checked before enforcement action.
  • Barcode/QR decoding records an identifier; it does not itself prove compliance.
  • LableLens provides compliance decision support; it does not establish regulatory authority or issue legal notices.

Evidence scope

Partial evidence means absence from the OCR cannot prove absence from the package. Missing fields therefore remain “Needs review.”

Complete package/listing is a user assertion that all declaration-bearing evidence was supplied. A missing mandatory field can then be screened as potential non-compliance.
